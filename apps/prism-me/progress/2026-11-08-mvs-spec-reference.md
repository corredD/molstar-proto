  like `packages/sequences/_spec/`: a README (what MesoViewSpec is, the packages and their entries, principles,

- **Tests:** the check itself (quick): a stale table fails it (a test edits a copy), a missing header fails it, a broken

- **Touches:** `packages/mesoscale/_spec/*` (new files, design.md trimmed to links where text moves),

## Decided

- **Split plan (Opus, step 1).** Topic files have an H1, a line linking README, unnumbered headings (stable slugs);
  design.md keeps its numbering and each moved section leaves a one-line stub heading linking the topic file (the stubs
  are the section-to-file map; old citations in progress files keep resolving). One file added beyond the brief:
  `streaming.md` (6.8 is ~470 lines). Moves (HEAD design.md lines): format.md 3.1-3.7, 3.9-3.11, 3.13, 3.14, 7.1;
  mesoql.md 3.8; ir.md 4.1-4.3, 7.2; runtime.md 4.4, 4.5, 6.1-6.3, 6.4, 6.5, 6.7, 7.3, 7.4; streaming.md 6.8 (to 6.8.6)
  and 6.8.8; views.md 5, 5.1. Stays: intro and version tables, 1, 2, 3.12, fragments answering decisions, 6.6, 6.8.7,
  8-13.
- **Commits:** README; one pure-move commit per file (byte-identical, later ranges cut first); edits (headings, links,
  version tags); dedupe against generated references; citation fixes outside `_spec`.
- **Avoid duplication:** README defines terms/principles/packages one line each; topic files state meaning and contracts
  and link back; design.md holds why, numbers, decisions; a generated table is never retyped in prose.

- **Beyond the brief (to record):** `@typescript/typescript6` added as a devDependency of the spec package (TS 7 has no
  JS API; Seq* does the same), with its lockfile entry; `issues.ts` registers the missing codes. The `spec` script takes
  `check` (default) or `generate`.
- **Left open:** doc.ts (mvs-patch's file) still cites `design.md §x`, so `reference/format.md` quotes those citations
  and "v0.4"; fix after mvs-patch merges, then `spec generate`. Sources outside doc.ts, sexpr.ts and the Prism adapter
  and session were rewritten; those keep working through the design.md stubs.

## Learned

- A check that reads the code finds what the types let through: `IssueCode` accepts any `x.y`, so 18 codes had never
  been registered. Regex readers of call shapes need a test per shape (`issue(`, validate's `err(`, mesoql's prefixed
  `err(`).
- Biome reflows a line a script just wrote: edit by exact text after formatting, or format last.
- `r5-1000.perf` is SIGKILLed when the heavy lane runs it beside the others on this machine; alone it passes.
