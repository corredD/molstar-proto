## Decided before code

- **Stated vs default colors** (§5.3, "Defaults when a look has no color"): the adapter draws a document list in
  spacefill, whose default color theme is `particle-index` (a color per copy). Writing no color layer for a look with no
  stated color would open every document in that theme instead of the runtime's per-population palette (`defaultColor`).
  **Ludo, 2026-11-09: option A.** The IR keeps stated and default colors apart; the adapter keeps writing the default
  layers unless the list's theme is one the person chose (By zoom on, or a theme other than spacefill's default), and
  then writes stated colors only. Written into prism.md §5.3 by this lane.

## Built

- **The owner port** (`packages/extensions/mesoscale/src/owner.ts`):
  `ParticleListOwner { owns, info, propose, themeChanged? }`, registered per plugin (`registerParticleListOwner`); the
  extension imports nothing of `meso-*`. `entities`, `style`, `colors`, `importColors`, `theme` ask a list's owner
  first: entities and groups from `info` (never `mesoEntities` for an owned list), looks through `propose` in the same
  run. `theme` proposes an owner's lists together inside its one transaction; By zoom (`theme`, `colorLevels`) on an
  owned list calls `themeChanged`. `info.aliases`: an entity found by label, then population id.
- **The document's side** (`packages/mesoscale/molstar/src/list-owner.ts`, `DocumentListOwner`, registered by the
  mesoviewspec extension): a list's entities are its set's types; groups by the document's compartments (paths of ids)
  or Kind; an edit becomes `stylePatch` (`document-model.ts`): `l.style.<n>` by address, set and moved last, reset or a
  look left saying nothing removed, eyes/Show only/authored looks untouched, `v.prism` with no view. A group picked
  whole is `(in c.x)`, else `(population p.a p.b)`.
- **Option A**: `IRLook.colorDefault` (`runtime.ts`, `ir.ts`; the paired examples' IRs regenerated); the adapter
  (`prism-adapter.ts`) leaves default colors out of a list whose theme the person chose (By zoom on, or a theme other
  than the representation's default), `redrawLooks` for `themeChanged`.
- **`mesoviewspec.look`** (a CSS color or the default, visible, transparency, emissive) and a document row's ⋯ › Color…
  (swatches, Default color; not on a part's row).
- **Docs**: prism.md §5.3 (option A and why not B; the port and `.look` as built), features.md, the changelog.
- **Tests**: `extensions/mesoscale/_test/owner.test.ts` (a fake owner: entities, style with a group, colors, import,
